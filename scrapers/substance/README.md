# Substance 3D Designer Node Scraper

Este script extrae el catálogo de nodos interno de la API de **Adobe Substance 3D Designer** utilizando el módulo integrado `sd`.

## Instrucciones de Uso

1. Abre **Substance 3D Designer**.
2. Ve al menú superior y selecciona `Windows > Python Editor`.
3. Haz clic en el icono de **abrir archivo** (la carpeta) o simplemente crea un nuevo archivo en blanco en el editor integrado.
4. **Copia** todo el contenido del archivo `substance_scraper.py`.
5. **Pega** el código en el Python Editor de Substance.
6. Haz clic en el botón de **Play** (Run Script) o presiona `F5`.
7. El script leerá el catálogo completo a través del módulo de definiciones de nodos y guardará un archivo `substance_nodes.json` en tu carpeta de **Documentos** (`C:\Users\TuUsuario\Documents\substance_nodes.json`).

Una vez lo tengas, ese archivo JSON será compatible con el formato estándar de Nodle.
